Every few years I decide I should write more, set up a blog, publish two posts,
and then let it go quiet. This is the latest attempt.

The thing that usually kills it is friction. If publishing means fighting a CMS,
remembering a password, or waiting on a build, I won't do it. So this site is
about as simple as it gets: a folder of Markdown files in a Git repo. Writing a
post means adding a file. Publishing means pushing.

## What I'll write about

Mostly whatever I've been working on — notes that are too long for a message and
too rough for anything formal. Half-finished ideas are fine here.

## How this works

Posts live in `_posts/` and are named by date:

```
_posts/2026-09-21-hello.md
```

The top of each file is a small block of metadata:

```yaml
---
title: "Starting a blog, again"
date: 2026-09-21
summary: "Shows up on the homepage."
---
```

Everything below that is just Markdown. That's the whole system.
